## 확정에서 파생되는 제약

- 훅이 지도이고 회피가 공간 회피 -> 러닝 중 화면을 봐야 함. 안전·배터리 설계가 최우선 과제가 됨
- 예산 월 5만원 -> 유료 라우팅 API(TMAP 건당 10원)와 라우팅 서버 자체 호스팅(월 $40~100) 모두 불가. 무료 한도 안에서 해결해야 함
- 카메라 AR 제외 -> AR은 "지도 위 AR"로 정의. Unity 등 게임엔진 불필요
- 안드로이드 단독 -> 백그라운드 위치 포그라운드 서비스, Play 위치 권한 심사가 초기 리스크

## MVP 경계 초안

### 포함

- 안드로이드 단독
- 지도에 내 위치 + 적 1~3마리 실시간 표시
- 목적지 자동 지정 (반경 기반), 제한 시간
- 위협 게이지 방식 잡힘 판정
- 난이도 티어 3단계 (치와와 / 셰퍼드 / 사자)
- 오디오 경보 (사전 생성 TTS 30~50개, 방향·거리·긴급도)
- 결과 화면 (시간, 거리, 페이스, 성공/실패)
- 로컬 기록 + 서버 리더보드 (익명 인증)

### 제외

- 카메라 AR, 워치, 스마트 글래스
- 실시간 멀티플레이, 크루, 친구
- 실시간 TTS/LLM 내레이션
- 스토리 미션, 기지 건설 등 메타 진행
- 소셜 로그인, 프로필
- iOS

### 제외 이유

- 월 5만원 예산과 1인 개발에서 코어 루프 완성도를 먼저 확보
- 위 항목은 코어 루프가 재미있다고 확인된 뒤 붙여도 늦지 않음
